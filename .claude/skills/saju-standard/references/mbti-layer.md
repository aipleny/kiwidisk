# MBTI 레이어 (L3)

`engine/mbti_layer.py`. 설계서 §4.

## 원칙
- 사용자가 스스로 밝힌 4글자 유형만 받는다. 사주로 MBTI를 추정하지 않는다.
- 사주 엔진을 import 하지 않는다. `interpret.py` 출력 JSON을 데이터로만 받는다.
- 모든 결과에 `note`: "이론적 매핑(가설)입니다. 사주에서 MBTI를 판정하지 않으며, 검증된 상관관계가 아닙니다."

## 기능

| 키 | 내용 | 쓰는 곳 |
|---|---|---|
| `stack` | 인지기능 주·부·3차·열등 (Beebe 모형) | 설명용 |
| `tone.rules` | E/I·S/N·T/F·J/P별 전달 규칙 4줄 | 풀이 전체 말투 |
| `compare.axes` | 축별 사주 기울기 vs 자기보고 글자, `talking_point` | "타고난 결 vs 지금의 나" 장 |
| `timing.periods` | 세운·대운 지지 십신군 → 주제 → 해당 인지기능의 위치(강점/성장 과제) | 8·9장 덧붙임 |
| `compat` | 사주 궁합(일간합·일지합충·용신 보완) + MBTI 궁합(기능 공유·주/열등 보완·S/N, 연애/팀 모드) | 궁합 |

## 이론적 매핑 (가설)

| 축 | 앞 글자 쪽 신호 | 뒷 글자 쪽 신호 |
|---|---|---|
| E/I | 식상 1.0, 비겁 0.5, 화 0.5, 목 0.3 | 인성 1.0, 수 0.5, 금 0.3 |
| S/N | 재성 1.0, 토 0.5 | 인성 0.7, 상관 0.6, 수 0.3 |
| T/F | 관성 0.6, 재성 0.5, 금 0.5 | 식신 0.6, 정인 0.5, 화 0.3, 목 0.3 |
| J/P | 관성 1.0, 정인 0.4 | 식상 0.8, 편재 0.3, 편인 0.3 |

차이 > 0.5면 해당 쪽으로 기울었다고 보고, 그 사이는 "균형".

| 십신군 | 시기 주제 | 연결 인지기능 |
|---|---|---|
| 비겁 | 자기주도·독립·경쟁 | Ti Fi Se |
| 식상 | 표현·창작·말하기 | Ne Se Fe |
| 재성 | 실행·성과·현실 관리 | Te Se Si |
| 관성 | 책임·규범·조직 안의 역할 | Te Si Fe |
| 인성 | 배움·성찰·내면 정리 | Ni Si Ti Fi |

## 검증 계획
위 매핑이 실제로 맞는지는 동의를 받은 실사용자의 (출생정보, 자기보고 MBTI) 쌍으로만 확인할 수 있다(설계서 §5.3). 그 전까지 이 표는 대화 소재를 만드는 장치로만 쓴다.
