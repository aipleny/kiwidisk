# 해석 표준 (L2 규칙 + 서술 근거 사전)

`engine/interpret.py`가 아래 1~6을 결정론으로 계산한다. LLM은 그 결과와 7~9의 사전만 근거로 문장을 쓴다.
원전 태그: [적천수] 억부·기세 / [궁통보감] 조후 / [자평진전] 격국·상신 / [연해자평]·[삼명통회] 신살·기초. 원문은 인용하지 않으며 `verify:원전` 항목은 실물 서적 검수 대상이다.

## 1. 강약 [적천수]

위치 가중치(합 100, 시주 미상이면 나머지로 정규화): 연간 10 · 연지 10 · 월간 10 · **월지 30** · 일지 15 · 시간 10 · 시지 15. 지지는 지장간 정기의 오행으로 본다. 비겁·인성 자리의 가중치 합이 점수.

| 점수 | 등급 |
|---|---|
| 80~ | 극신강 (종왕 후보) |
| 60~79 | 신강 |
| 40~59 | 중화 (50 이상이면 강 쪽) |
| 20~39 | 신약 |
| ~19 | 극신약 (종격 후보) |

보조 판단: 득령(월지), 득지(일지), 득세(나머지 과반), 통근(지장간 어디든 비겁·인성 오행).

## 2. 조후 [궁통보감] — 원전 대조 완료(2026-10-07)

일간 10 × 월지 12 = 120칸 조후 용신표는 `references/johu-qiongtong.json`에 있고 엔진이 그대로 읽는다. 각 칸에 `stems`(본문이 직접 처방한 용신, 우선순위 순), `conditional`(조건부·대체 용신), `evidence`(원문 인용)를 둔다.
대조 방법: 『穷通宝鉴』 원문 2판본(殆知阁본, scripta-sinica본)에서 일간×월 단락의 先·次·专用·为主·为佐 표현으로 우선순위를 정했다. 기존 기억 기반 표와 비교해 106칸 일치, 8칸 1순위 오류, 6칸 용신 누락·추가가 있어 원문대로 고쳤다(`previous`, `status_vs_previous` 필드에 기록). 원문이 모호한 칸(戊寅·戊卯 결자, 乙丑·丁丑 十二月 단락 없음 등)은 `note`에 적었다.
기후: 亥子丑 = 한(寒, 화 필요), 巳午未 = 난(暖, 수 필요), 그 외 = 온.
**조후 우선**: 子·丑·午·未월이고 필요한 오행의 지장간 가중치가 1.0 미만일 때.

## 3. 격국 [자평진전] — 원전 대조 완료(2026-10-07)

근거 인용과 판정은 `references/gyeokguk-ziping.json`(『子平真诠』 원문 대조, 규칙별 status·quotes·proposed_fix).

**취격**
1. 월지가 일간의 건록 → 건록격 / 양간의 양인 → 양인격
2. 월지를 포함한 삼합이 온전하고 그 오행이 일간과 다르면 그 국(局)으로 변격(丁生亥月, 支全卯未, 则化为印)
3. 월지 지장간을 정기→중기→여기 순으로 보며 처음 투출한 것을 격으로(不透甲而透丙, 同知得以作主). 그것이 일간 오행이면 월겁격. 투출이 없으면 정기. 함께 투출한 다른 지장간은 `also`(겸격)
4. 일간을 제외한 천간끼리 오합으로 묶인 십신은 '없는 것'으로 본다(합살유관·합상존관 등)

**성패** (상태: 성격 / 성격(하)=격은 서나 낮음 / 대기=带忌 / 파격 / 미정)

| 격 | 성격·구응 | 대기·파격 |
|---|---|---|
| 정관 | 재·인 보좌, 상관을 인이 구함, 편관이 합으로 제거 | 관살혼잡, 상관견관(인 없음), 인으로 구했는데 재 투출, 관이 합으로 묶임(대기), 재·인 없음(성격(하)) |
| 편관 | 식신제살(재 있어도 무방), 살인상생, 양인이 대적 | 정관 함께 투출(대기·取清), 식제+인 투출·재 없음(대기), 인+재(파격), 재만 있고 제어 없음(파격) |
| 재 | 식상생재, 재왕생관, 재투칠살을 식신이 제어, 겁재를 식상·관이 구함 | 재투칠살, 군겁쟁재, 재왕생관에 식상 섞임(대기) |
| 인 | 관인상생, 겁재호인, 재가 있어도 겁재·합·인다로 구함 | 재극인(구제 없음), 신강 인중에 칠살 투출, 재극인을 관만으로 통관(성격(하)) |
| 식신 | 식신생재, 식신제살, 효신을 재가 제어, 효신을 칠살로 취격 | 효신탈식(정인·편인 모두), 생재노살 |
| 상관 | 상관생재, 상관패인, 상관가살, 금수상관(庚辛일 亥子월)은 관을 기뻐함 | 상관견관(금수 아님·인 없음), 상관생재 투살, 패인에 재(대기) |
| 양인 | 관살이 양인을 제어 | 관살 없음(파격, 단 재와 식상이 함께면 성격(하)), 관살을 식상이 제거(인 없음) |
| 건록·월겁 | 용관+재·인, 용살+식상, 용재+식상, 식상 설기 | 관살혼잡(대기), 용관에 상관, 용살에 재, 재관 없이 인만, 용재에 식상 없음(성격(하)) |

**월령 형충**: 월지가 연·일·시지와 충이면 파격(刑冲用神, 尤为破格). 단 辰戌·丑未는 冲动이라 제외, 월지가 다른 지지와 육합·삼합(반합)을 이루면 풀린 것으로 본다.

상신: 정관→재·인 / 편관→식상·인 / 재→식상·관 / 인→관·비겁 / 식신→재·비겁 / 상관→재·인 / 건록·월겁→관·재·식상 / 양인→관.

## 4. 용신 결정 (§3.1 5단계)

1. **종격**: 점수 ≥85 & 관살 천간 무투 → 종왕(비겁). 점수 ≤15 & 무근 → 식상·재·관 중 최강에 종(종아·종재·종살).
2. **조후 우선** 플래그 → 조후표 1순위 오행.
3. 그 외 **억부**:
   - 신강: 인성 > 비겁이면 재성 / 비겁 과다면 관성(관이 약하고 재도 약하면 식상)
   - 신약: 극설 중 재성이 가장 무거우면 비겁, 아니면 인성
4. 신뢰도: 채택 용신이 억부·조후·격국상신 중 2개 이상과 일치 → 높음, 1개 → 보통, 0개 → 낮음(학파별 이견 큼을 고지).
5. 희신 = 용신을 생하는 오행. 단, 억부에서 신약인데 그 오행이 극설(식상·재·관)이면 나머지 생부 오행(용신이 인성이면 비겁, 비겁이면 인성)으로, 신강인데 생부(비겁·인성)이면 용신이 생하는 오행으로 바꾼다. 기신 = 용신을 극하는 오행.

## 5. 운 길흉

간지별 점수 = 0.4 × 천간 + 0.6 × 지지(정기). 용신 +2, 희신 +1, 기신 −2, 억부로 정한 경우 강약 방향을 거스르는 오행(신약에 식상·재·관, 신강에 비겁·인성) −1, 그 외 0. 각 운에는 원국과의 합·충·형·파·해(`natal`)를 함께 낸다. ≥0.8 길 / ≤−0.8 흉 / 사이 평. 표현은 "흐름이 순하다/거칠다" 수준으로 하고 사건을 단정하지 않는다.
