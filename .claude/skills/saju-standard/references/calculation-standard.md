# 계산 표준 (L1) 요약

전체 근거: `docs/saju-standard-design.md` §2, `docs/engine-comparison-2026-10.md`.

## 파이프라인

```
입력(양력/음력·윤달) ─ lunar-python 음력→양력
  │
  ▼ 법정 시각 → UTC : IANA Asia/Seoul
  │   1948~51·1955~60·1987~88 서머타임, 1954-03-21~1961-08-09 UTC+8:30
  │   공백 시각 → 앞으로 밀고 경고 / 중복 시각 → 앞선 시각 + 경고
  │
  ├─▶ UTC+8 환산 → lunar-python 절기 판정 → 연주(입춘)·월주(12절)
  │     ※ 라이브러리 절기 시각은 UTC+8 기준. 한국 시계 시각을 그대로 넣으면 1시간 오류.
  │
  └─▶ LMT = UTC + 경도×4분 [+ 균시차(옵션)] → 일주·시주
        자시 23:00~24:00: yaja(기본: 당일 일주, 다음날 기준 시간) / jeongja(다음날 일주) / midnight(당일 기준)
```

## 경계 경고
- 절입 ±30분 → `alternatives.jie`에 절입 전·후 연·월주
- 시 경계 ±15분 → `alternatives.hour`
- 자시 구간 → `alternatives.zishi`에 세 학파 결과
- 시각 미상 → 시주 없음, 정오 기준

## 대운
양남음녀 순행, 음남양녀 역행. 대운수 = 다음(순)·이전(역) 절까지 일수 ÷ 3 (1일 = 4개월, 월 단위 반올림).
