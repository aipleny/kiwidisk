# 표준 사주 스킬 + MBTI 레이어 설계서 (v0.1)

> 상태: 설계 초안. 엔진 교차검증(§5) 결과에 따라 §2의 엔진 선택이 바뀔 수 있다.

## 0. 목표와 원칙

1. **계산은 결정론, 해석은 근거 기반.** 명식(사주팔자)은 코드가 계산하고, LLM은 계산 결과에 근거해서만 해석한다. LLM이 간지를 암산하지 않는다.
2. **학파 차이는 숨기지 않고 옵션·경고로 드러낸다.** 자시 처리, 진태양시, 용신 학설처럼 정답이 갈리는 지점은 기본값을 정하되 결과에 명시한다.
3. **MBTI는 사주에서 추론하지 않는다.** 사용자가 스스로 밝힌 유형만 받아서, 사주와 *나란히* 놓고 비교·대화하는 레이어로만 쓴다.
4. **정확도 주장은 검증 데이터로만 한다.** "몇 개 엔진이 같은 답을 냈다"가 아니라 "독립 기준(천문 계산·KASI 자료)과 몇 건 중 몇 건 일치"로 말한다.

## 1. 전체 구조

```
입력(생년월일시·양/음력·윤달·출생지·성별·[MBTI])
   │
   ▼
[L1 계산 엔진]  시간 정규화 → 사주 4주 → 지장간·십신·12운성·신살·합충 → 대운/세운
   │   (결정론, JSON 출력, 경계 경고 포함)
   ▼
[L2 해석 기준]  강약(억부) → 조후 → 격국 → 용신 결정 → 영역별 해석 근거표
   │   (규칙 테이블 + 원전 태그, 결정론 부분과 LLM 서술 부분 분리)
   ▼
[L3 MBTI 레이어] 말투 개인화 / 비교 카드 / 시기×인지기능 / 이중 궁합
   │   (사주 엔진과 import 무접점, 별도 모듈)
   ▼
[출력] 명식표 + 장별 풀이 + 상담 모드
```

스킬 디렉터리(예정):

```
.claude/skills/saju-standard/
  SKILL.md                     # 진입점: 입력 수집 → 엔진 호출 → 해석 절차
  engine/                      # L1 (선정된 엔진 + 시간 정규화 래퍼)
  references/
    calculation-standard.md    # §2 요약
    interpretation-standard.md # §3 규칙표
    mbti-layer.md              # §4
  tests/                       # §5 검증 세트
```

## 2. L1 계산 표준

### 2.1 시간 정규화 파이프라인 (순서 고정)

| 단계 | 처리 | 기본값 |
|---|---|---|
| ① 달력 | 음력이면 양력으로 변환(윤달 플래그 필수) | 양력 |
| ② 역사적 표준시 | 출생 당시 한국 법정 시각 → UTC. 1954-03-21~1961-08-09 UTC+8:30, 1948~51·1955~60·1987~88 서머타임 반영(IANA `Asia/Seoul`) | 항상 적용 |
| ③ 진태양시 | UTC + 출생지 경도/15h = 지방평균태양시(LMT) | 적용, 출생지 미상 시 서울 126.98°E |
| ④ 균시차 | LMT + 균시차 = 진태양시 | **끔**(옵션). 결과에 켰을 때 값을 병기 |

> 근거: 한국 만세력 앱 대부분은 ③까지 적용하고 ④는 생략한다. ④는 최대 ±16분이라 시주 경계 근처에서만 의미가 있으므로, 기본은 끄고 경계 경고(§2.4)로 처리한다.

### 2.2 기둥별 규칙

| 기둥 | 규칙 |
|---|---|
| 연주 | 입춘(태양황경 315°) **절입 시각** 기준. 양력 1/1·음력 설 아님 |
| 월주 | 12절(입춘·경칩·청명…소한) 절입 시각 기준. 월간은 연간으로 결정(갑기년 병인월…) |
| 일주 | 60갑자 연속 계산. 날짜 변경 시각은 §2.3 |
| 시주 | 진태양시 기준 2시간 단위(子 23:00~01:00). 시간은 일간으로 결정(갑기일 갑자시…) |

### 2.3 자시(23:00~01:00) 처리 — 옵션

| 모드 | 23:00~24:00 일주 | 23:00~24:00 시주 천간 | 비고 |
|---|---|---|---|
| `yaja` (기본) | 당일 | 다음날 일간 기준 | 야자시/조자시 구분. 한국 앱 다수 |
| `jeongja` | 다음날 | 다음날 일간 기준 | 23시에 날이 바뀜(정자시설) |
| `midnight` | 당일 | 당일 일간 기준 | 단순 자정 기준 |

해당 구간 출생이면 결과에 **세 모드의 일주·시주를 모두 병기**하고 기본 모드를 표시한다.

### 2.4 경계 경고

- 절입 시각 ±30분 이내 → 연/월주 후보 2개 병기
- 시 경계 ±15분 이내(보정 후 기준) → 시주 후보 2개 병기
- 시간 미상 → 시주 null, 오행·십신 집계는 6글자 기준임을 명시

### 2.5 파생값

지장간(여기·중기·정기), 십신, 12운성, 공망, 주요 신살(도화·역마·화개·천을귀인·양인·백호·괴강 등), 천간합·지지 육합/삼합/방합·충·형·파·해, 대운(순역: 양남음녀 순행, 대운수 = 절입까지 일수 ÷ 3, 월 단위 반올림), 세운.

### 2.6 엔진 선정 기준

1. §2.1~2.3을 모두 지원하거나 래퍼로 감쌀 수 있을 것
2. **독립 기준과의 일치율**(§5)이 최고일 것
3. 의존성 최소, 라이선스 허용(MIT 등), 결정론
4. JSON 출력 스키마가 §2.5를 담을 것

**1차 교차검증 결과(`docs/engine-comparison-2026-10.md`)에 따른 결정:** 단독으로 표준을 만족하는 공개 엔진은 없다. 시간 정규화(§2.1)는 자체 구현하고, 연·월주는 lunar-python에 UTC+8로 환산한 순간을 넣어 구하며(KASI와 분 단위 일치), 일·시주는 LMT와 자시 모드(§2.3)로 자체 계산한다. adminhelper(자체 천문)·jeomsin(자체 근사식)은 회귀 테스트 대조군으로 쓴다.

## 3. L2 해석 표준

### 3.1 감명 절차 (고정 순서)

1. **일간과 월령** — 일간 오행, 월지에서 득령 여부
2. **강약(억부)** — 득령·득지·득세 점수화 → 신강/중화/신약 5단계. 극단치는 종격 후보로 표시
3. **조후** — 월지 계절 × 일간으로 한난조습 판정. 조후가 극단(예: 子·丑월 庚辛·壬癸, 午·未월 丙丁)이면 조후 우선 플래그
4. **격국** — 월지 정기·투출 기준 8정격(정관·편관·정재·편재·정인·편인·식신·상관) + 건록격·양인격. 성격/파격 판정
5. **용신 결정 규칙**
   - 조후 우선 플래그가 있으면 → 조후용신
   - 종격 조건 충족 → 종하는 오행
   - 그 외 → 억부용신, 격국의 상신(相神)과 일치하면 신뢰도 '높음'
   - 결과에 **세 관점의 후보를 모두 표시**하고 채택 근거를 한 줄로 남김
6. **운의 흐름** — 대운·세운이 용신/기신과 맺는 관계, 원국과의 합충
7. **영역별 해석** — 궁위(연=조상·초년, 월=부모·사회, 일=본인·배우자, 시=자녀·말년) × 십신

### 3.2 원전 태그

해석 규칙마다 출처 계열을 태그로 단다: `[자평진전]` 격국·상신, `[적천수]` 억부·기세, `[궁통보감]` 조후, `[연해자평]`·`[삼명통회]` 신살·기초. 원문 직접 인용은 하지 않으며, 원문 확인이 필요한 규칙은 `verify:원전` 표시 후 실물 서적으로 검수한다.

### 3.3 결정론/서술 분리

- 결정론(코드): 강약 점수, 조후 플래그, 격국 판정, 용신 후보 → JSON
- 서술(LLM): 위 JSON + 규칙표만 근거로 문장 작성. JSON에 없는 판단은 쓰지 않는다

### 3.4 안전 원칙

수명·중병·이혼·파산 단정 금지, 부적·굿 권유 금지, 타인 사주 단정 금지, 모든 풀이 끝에 참고용 고지.

## 4. L3 MBTI 레이어

### 4.1 입력

- 사용자가 밝힌 4글자 유형(필수), 선택적으로 축별 선명도(예: E 60%) 또는 12문항 간이 문항
- 유형을 모르면 레이어를 끈다. **사주로 유형을 추정하지 않는다**

### 4.2 기능 (우선순위 순)

1. **말투 개인화** — 같은 해석을 T형은 근거·구조 중심, F형은 관계·감정 중심, J형은 계획표, P형은 선택지로 전달. 내용은 바꾸지 않고 전달 방식만 바꾼다
2. **"타고난 결 vs 지금의 나" 비교 카드** — 아래 이론 매핑으로 사주 쪽 경향을 축별로 표시하고 자기보고 MBTI와 일치/불일치를 보여준다. 불일치는 "환경·역할로 발달한 면" 같은 대화 소재로 쓴다
3. **시기 × 인지기능** — 대운·세운의 십신을 성장 과제로 번역(예: 식상운 → 열등기능 사용 연습)
4. **이중 궁합** — 사주 궁합(합충·오행 보완) + MBTI 인지기능 궁합을 한 표에. 연애/팀 모드 분리

### 4.3 이론 매핑표 (가설, 검증 전)

| 사주 신호 | 연결되는 성향 축(가설) |
|---|---|
| 식상 강 | E 쪽 표현성, Ne/Se |
| 인성 강 | I 쪽 내면화, Ni/Si |
| 관성 강 | J 쪽 규범·구조 |
| 재성 강 | S 쪽 현실·실용, Te |
| 비겁 강 | 자기주도·독립(Ti/Fi 경향) |
| 화·목 우세 | 외향 에너지 |
| 수·금 우세 | 내향·분석 |

이 표는 **해석상의 대응일 뿐 검증된 상관이 아니다.** 결과에 항상 "이론적 매핑" 라벨을 붙인다.

### 4.4 분리 원칙

MBTI 모듈은 사주 엔진을 import하지 않고, 사주 JSON과 MBTI JSON을 해석 단계에서만 합친다(samsin-saju `mbti_engine.py`의 무접점 설계를 계승).

## 5. 데이터·검증 계획

"데이터 수"는 목적에 따라 두 종류다.

### 5.1 계산 정확도 — 테스트 케이스를 늘린다 (사람 데이터 불필요)

| 세트 | 규모 | 기준 |
|---|---|---|
| T1 절입 경계 | 1900~2099 × 24절기 × 경계 ±1분 ≈ 19,200건 | 천문 계산(VSOP87 기반)·KASI 절기표 |
| T2 일주 연속성 | 1900~2099 전 일자 ≈ 73,000건 | 60갑자 산술 |
| T3 무작위 교차 | 시각 무작위 10만 건 | 엔진 간 다수결 + 불일치 수동 검토 |
| T4 역사적 시간대 | 1948~61·1987~88 경계 수백 건 | IANA tzdata |
| T5 음력 변환 | 1900~2099 윤달 포함 | KASI 음양력 자료 |
| T6 자시·시 경계 | 각 모드 × 경계 ±1분 | §2.3 규칙 |

### 5.2 해석 커버리지 — 가능한 명식 전수

연주 60 × 월주 12 × 일주 60 × 시주 12 = **518,400가지** 명식(성별·대운 방향 ×2). L2 결정론 부분(강약·격국·용신 후보)을 전수 실행해 예외·모순·분포 이상을 잡는다.

### 5.3 MBTI 가설 검증 — 이때만 사람 데이터가 필요

§4.3 매핑이 실제로 맞는지는 **동의를 받은 실제 사용자**의 (출생정보, 자기보고 MBTI) 쌍으로만 확인할 수 있다. 수집 시 개인정보 최소화(이름·연락처 미수집), 통계는 집계값만 보관. 의미 있는 상관을 보려면 축당 수천 명 규모가 필요하다.

## 6. 진행 순서

1. ✅ 공개 스킬 수집·정적 비교
2. ✅ 엔진 교차검증 1차(경계 14건) → 엔진 방침 확정 (§2.6)
3. L1 래퍼 작성(§2.1 파이프라인 + §2.3 모드 + §2.4 경고)
4. L2 규칙표·결정론 모듈 → 518,400 전수 테스트
5. L3 MBTI 모듈(말투 개인화 → 비교 카드 → 궁합)
6. `saju-standard` 스킬로 묶어 배포, 기존 `saju` 스킬은 참고용으로 유지
